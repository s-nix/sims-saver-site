One-line install

Downloads the latest version, checks it against the published hash, installs it and starts it.

Linux and macOS. Paste into a terminal.
curl -fsSL https://sims-saver.nix.uno/install.sh | sh
Windows. Paste into PowerShell.
irm https://sims-saver.nix.uno/install.ps1 | iex
Installs for your user only, so there is no sudo or admin prompt. On Linux, --system installs the .deb or .rpm through your package manager instead, and --flatpak installs the Flatpak (the default on Steam Deck).

Have an invite code?

If someone is hosting storage for you, they will give you a code that starts with SIMS1-.

  1. Install the app.
  2. Name your computer and check the Sims folder it found.
  3. On the Storage step, paste the code into "Have a code from a friend?" and click Use code.
  4. Click Start syncing.

How it works

Sims Saver watches your Sims folders. When the game writes a save, the app waits a few seconds for it to finish, then uploads it. Your other computers check for changes about once a minute and download what is new.

If two computers change the same save before they have synced, neither copy is thrown away. The newer one keeps its name and the older one is saved next to it as a "conflict from" copy, which shows up in the game as a separate save. You can pick one in the app's Conflicts tab or just leave both.

Storage can be S3-compatible (Backblaze B2, Cloudflare R2, Wasabi and others), WebDAV or Nextcloud, SFTP, a network share, Google Drive, Dropbox, OneDrive, or a plain folder. You can set a passphrase so that files are encrypted before upload; then the storage host cannot read them, and neither can you without the passphrase.
